# Classical - Quantum Hybrid Classifier

# Anvesha 2025 Science Expo Project

**Debashis Saikia**  
**Avinash Chauhan**


We present a novel, efficient Quantum-Classical Hybrid Classification protocol that utilizes three conventional algorithms: K-Means, PCA, and Quantum Circuit. Our Method uses PCA for variance-alligned dimensionality reduction, followed by K-Means to select representative centroids. The core classification involves a UU† quantum circuit, which directly measures the state overlap probability between an encoded data point (Ψ) and the encoded centroid state (Φ). This approach establishes a probabilistic, distance-based decision rule, making it ideal for fast, interpretable classification on near-term quantum hardware.
